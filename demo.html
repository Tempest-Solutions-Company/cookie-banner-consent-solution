Getting Started

Include the library and initialize with your preferred options:

<link rel="stylesheet" href="gdpr-cookie-consent.css">
<script src="gdpr-cookie-consent.js"></script>

<script>
  const gdprConsent = new GDPRCookieConsent({
    regulatory: 'auto',  // 'gdpr', 'ccpa', or 'auto'
    theme: 'light',      // 'light' or 'dark'
    position: 'bottom',  // 'bottom' or 'bottom-right'
    cookieCategories: [
      { id: 'necessary', name: 'Necessary', 
        required: true },
      { id: 'analytics', name: 'Analytics', 
        required: false }
    ],
    securityOptions: {
      cookieSecure: true,
      storageEncryption: true,
      consentVerification: 'strong'
    }
  });
</script>

Regulatory Support

This solution helps you comply with:

  • GDPR - European Union's General Data Protection Regulation

  • CCPA - California Consumer Privacy Act

Note: Proper legal documentation and implementation are still necessary.

Security Implementation

All security features include graceful fallback when browser support is limited:

  • Falls back to standard storage if Web Crypto API isn't supported
  • Degrades verification level when advanced features aren't available
  • Maintains basic security even without advanced browser features
  • Respect for privacy signals with minimal fingerprinting
